# KB-11 Exporting your data and projects

- **Code:** Project menu > Export > Download ZIP. You get the full source code, which you own and
  can run anywhere. With GitHub sync (KB-07) the code is also in your repository.
- **Database:** Project menu > Database > Export gives one CSV file per table.
- **Deleted projects** can be restored from Settings > Trash for 30 days, then they are removed for
  good.
- **Backups:** we take a database snapshot of every deployed app once a day and keep 7 days.
  Restoring a snapshot is done by support; contact us with the project name and the date and time
  you want to go back to.
