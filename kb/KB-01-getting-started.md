# KB-01 Getting started with Buildbox

Buildbox turns a written description into a working web app. You type what you want ("a booking
page for my dog grooming business with a calendar and email reminders"), and Buildbox generates the
code, a database if the app needs one, and a live preview.

- **Prompt box.** Describe the app or the change you want. Short, specific prompts work best. One
  change per prompt is easier to review than five.
- **Preview.** The right-hand pane runs your app. Every generation updates it.
- **Code view.** You can read and edit the generated code directly. Your edits are kept; the next
  generation works on top of them.
- **History.** Every generation is a checkpoint. "Restore" puts the project back to that point.
- **Credits.** Each generation uses credits (see KB-02). Browsing, editing code by hand and
  deploying do not use credits.

Supported browsers: current Chrome, Edge, Firefox and Safari. If the preview is blank, try a hard
refresh first, then a private window with extensions off.
