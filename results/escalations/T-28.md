# T-28: Preview pane blank in Safari 19: TypeError on navigator.gpu.requestAdapter (works in Chrome)

| | |
|---|---|
| Severity | sev3 |
| Customer | lucy.grant@example.com |
| Received | 2026-09-22T09:25:00Z |
| Triage | tier 3, editor-and-generation, urgency normal |
| Suspected area | Preview pane front end calls navigator.gpu.requestAdapter without checking that WebGPU exists. In Safari 19 navigator.gpu is undefined, possibly because WebGPU is off or unsupported there. The preview needs a feature check and a fallback. |

**Customer impact.** One customer (lucy.grant@example.com) sees a blank white preview pane in Safari 19 on Mac. The preview works in Chrome, so she has a workaround. Nothing in the ticket suggests other customers are affected, but Safari users in general may be.

**Evidence (quoted from the ticket)**
- The preview pane is a blank white screen in Safari 19 on my Mac.
- Works fine in Chrome.
- TypeError: undefined is not an object (evaluating 'navigator.gpu.requestAdapter')

**Already tried by the customer**
- Hard refresh
- Private window

**KB checked:** KB-01. KB-01 says to try a hard refresh and then a private window with extensions off, and the customer has already done the hard refresh and the private window, and the console error points to missing WebGPU (navigator.gpu) in her Safari, which the KB does not cover.

**Questions for engineering**
- Does the preview runtime require WebGPU, and is navigator.gpu called without a feature check or fallback?
- Is Safari 19 on the supported browser list in KB-01, and is WebGPU enabled by default there or does it sit behind a feature flag?
- Are other Safari users reporting a blank preview, or did a recent preview release start calling navigator.gpu?
