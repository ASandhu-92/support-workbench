# T-28: Preview pane blank in Safari 19: navigator.gpu is undefined (WebGPU)

| | |
|---|---|
| Severity | sev3 |
| Customer | lucy.grant@example.com |
| Received | 2026-09-22T09:25:00Z |
| Triage | tier 3, editor-and-generation, urgency normal |
| Suspected area | Preview runtime calls navigator.gpu.requestAdapter without checking that WebGPU exists. In Safari 19, navigator.gpu is undefined (WebGPU may be unavailable or disabled), so the preview throws and renders nothing instead of falling back. |

**Customer impact.** Lucy Grant sees a blank white preview pane in Safari 19 on a Mac. The same project works in Chrome, so she has a workaround. Nothing in the ticket suggests other customers are affected, but Safari users in general may be.

**Evidence (quoted from the ticket)**
- Blank preview in Safari
- The preview pane is a blank white screen in Safari 19 on my Mac.
- Works fine in Chrome.
- TypeError: undefined is not an object (evaluating 'navigator.gpu.requestAdapter')

**Already tried by the customer**
- Hard refresh
- Private window

**KB checked:** KB-01. KB-01 lists Safari as supported and says to try a hard refresh and a private window with extensions off, but the customer already did the hard refresh and private window and the preview is still blank with a WebGPU error.

**Questions for engineering**
- Does the preview runtime require WebGPU, and should it feature-detect navigator.gpu and fall back to a non-GPU path in Safari 19?
- Is this specific to Safari 19 or to WebGPU being disabled in this customer's Safari settings, and does it reproduce on a clean Safari 19 install?
- Is the failing call in Buildbox preview code or in the code generated for this project, and does it affect other Safari users?
